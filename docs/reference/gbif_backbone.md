# Checklist-pinned \[rgbif::name_backbone()\]

Same interface as \[rgbif::name_backbone()\], with the checklist pinned
as in \[gbif_backbone_checklist()\].

## Usage

``` r
gbif_backbone(name, checklist = NULL, ...)
```

## Arguments

- name:

  (character) Name to match.

- checklist:

  Checklist spec, see \[gbif_checklist_key()\].

- ...:

  Passed on to \[rgbif::name_backbone()\].
