# Bounding box covering several points, expanded by a radius

Bounding box covering several points, expanded by a radius

## Usage

``` r
bbox_for_points(longitudes, latitudes, radius_km)
```

## Arguments

- longitudes, latitudes:

  (numeric) Point coordinates in decimal degrees.

- radius_km:

  (numeric) Radius in kilometres to expand the box by.

## Value

A list with \`xmin\`, \`xmax\`, \`ymin\`, \`ymax\`.
